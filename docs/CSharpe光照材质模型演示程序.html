C# OpenGL 光照与材质（Light & Material）演示程序 · 开发报告

 

. 项目概述

本项目是一个基于 OpenTK（C# 封装的 OpenGL 绑定）的 Windows Forms 桌面程序，用于演示 OpenGL 基础光照模型与材质系统。程序在窗口中以网格（3 行 × 5 列）方式绘制多个球体，每个球体应用不同的预设材质，配合光照着色器实时计算环境光、漫反射与镜面高光，直观比较不同材质（金属、宝石、塑料、橡胶等）的视觉表现。

核心特性：

  • 基于 OpenTK 4.9.3 的 OpenGL 4.x 风格渲染（#version 460 core 着色器源码内嵌）。

  • 支持三类光源：平行光（Directional）、点光源（Point）、聚光灯（Spot），并实现了距离衰减与聚光锥角。

  • 内置 15 种预设材质（翡翠、玉、黑曜石、珍珠、红宝石、绿松石、黄铜、青铜、铬、铜、金、银、绿色塑料、青色橡胶 + 一个全黑测试材质），材质库另有更多未启用的工厂函数。

  • 着色器内支持 Blinn-Phong 半角向量高光模型（可在 Phong 反射模型间切换）。

  • 渲染循环通过 Timer 定时刷新，自定义 GL 控件 OpenGLView 承载绘制。

. 开发环境与依赖

工程入口：Program.cs → Application.Run(new OpenTKMainForm())，主窗体为 OpenTKMainForm（Form1.cs），内含一个停靠填充（Dock=Fill）的 OpenGLView 控件和一个 Timer（50ms 间隔）。

. 核心模块详解

渲染主循环（Form1.cs）

OpenTKMainForm_Load 完成一次性初始化（相机、着色器、光源、材质、ClearColor、启动 Timer）。

openglView_Paint 为每一帧的绘制逻辑：

  1. 设置 GL.Viewport 并 GL.Clear(Color | Depth)、开启 DepthTest。

  2. 构造 15 个材质的数组，按 3×5 网格计算每格 (x, y) 偏移（spacingX=spacingY=4.5，球体缩放 0.85）。

  3. 对每个材质调用 m_SphereUseMaterial.SetPosition/SetScale/Draw(...) —— 注意：当前实际只走点光源着色器路径（m_DotLightShader + m_DotLight + blinn=true），详见 §7。

  4. SwapBuffers() 交换双缓冲。

m_SphereUseMaterial.SetPosition(x, y, 0.0f);
m_SphereUseMaterial.SetScale(0.85f, 0.85f, 0.85f);

着色器（Shader.cs + 内嵌 GLSL）

着色器源码以字符串形式内嵌在 Form1.cs：

  • 顶点着色器（m_vsShader）：#version 460 core，输出 FragPos / TexCoord / Normal，用 model/view/projection 计算 gl_Position。属性绑定固定为 location0=pos, location1=texcoord, location2=normal。

  • 三个片段着色器：分别处理平行光、点光、聚光；统一包含环境光 + 漫反射 + 镜面高光三段，并带 blinn 开关在 Phong（reflect）与 Blinn-Phong（halfway）间切换。

Shader 类在构造时编译链接，并遍历活跃 uniform 建立 Dictionary<string,int> 缓存，避免运行时重复查询。

球体几何（SphereUseMaterial）

在构造函数中生成 50×50 经纬网格球体（半径 2.0）：

  • 顶点位置按球面参数方程计算；法线 = 顶点位置归一化（球心在原点，故法线方向即位置方向，正确）。

  • 纹理坐标按网格比例生成（存在一处笔误，见 §7）。

  • 索引按两个三角形/格生成，交给内部 VertexArrayObject，分别绑定 position(0)/texcoord(1)/normal(2) 三个 VBO 与 EBO。

Draw(Camera, Shader, Material, LightBase, bool) 是 C++ 移植版绘制接口：绑定 shader → 上传 viewPos、blinn、材质四元组 → 按光源子类（平行/点/聚光）上行对应 uniform → 上传 projection/view/model 矩阵 → m_vao.Draw() → Unbind。

相机（Camera.cs）

经典 Look-At 相机：内部维护 eye/front/up，不保存 center（由 position+front 推出），支持 FOV（角度，限幅 1–160°）、近/远裁剪面，输出视图矩阵与投影矩阵。窗体初始化时相机置于 (0,1,13)、FOV 60°，以避免边缘球体透视畸变。

光照与材质模型

光照三分量（每种光源结构均含 ambient/diffuse/specular 三色）：

  • 环境光：ambient * material.ambient

  • 漫反射：diffuse * (max(dot(N, L),0) * material.diffuse)

  • 镜面高光：

    • Phong：pow(max(dot(V, reflect(-L, N)),0), shininess)

    • Blinn-Phong：pow(max(dot(N, halfway(L,V)),0), shininess)，halfway = normalize(L+V)

三类光源差异：

  • 平行光：方向固定，无衰减。

  • 点光源：方向 = position - FragPos，可扩展衰减（当前未启用衰减段）。

  • 聚光灯：在方向/位置基础上增加距离衰减（分段 CalculateAttenuation）与锥角强度（intensity = clamp((cosTheta - cosOuter)/(cosInner - cosOuter), 0, 1)）。

材质库：Material.cs 提供 27 个预设（翡翠、玉、黑曜石、珍珠、红宝石、绿松石、黄铜、青铜、铬、铜、金、银、黑/青/绿/红/白/黄塑料、黑/青/绿/红/白/黄橡胶），每个给出真实感的 ambient/diffuse/specular/shininess 取值。主程序实际展示其中 15 种。

已完成的移植修复（README 记录）

从 C++ 工程移植到 C# 时，已落实以下关键修复：

  1. 修正 SphereUseMaterial 顶点属性绑定顺序：location0=position / location1=texcoord / location2=normal，确保法线正确传入着色器。

  2. SphereUseMaterial 由「继承 VAO」改为「继承 Transform 并内部持有 VertexArrayObject」，分离绘制职责。

  3. 移植 C++ 风格的 Draw(Camera, Shader, Material, LightBase, bool) 接口用于上行 uniform 并绘制。

  4. 在 Form1 初始化处设置默认光源参数（direction/position/ambient/diffuse/specular），保证运行即可见光照。

  5. 调整相机初始位置与 FOV，并将球体布局改为可配置网格、缩小边缘球体以减轻透视畸变。

运行与测试

构建步骤（README）：安装 .NET 8 SDK → VS 打开 .sln → 还原 NuGet → 生成 → F5 运行。

预期表现：窗体以深青底色（ClearColor(0.2,0.3,0.3)）呈现 3×5 共 15 个带光照的球体，金属类有明显高光、宝石类色彩饱和、塑料/橡胶类低高光。

当前主循环实际走的是点光源 + Blinn-Phong 路径，因此若需对比三类光源效果，需手动切换 Draw 调用的 shader/light 参数（见 §7 建议）。

 

总结

本工程是一个结构清晰、适合教学的 C# + OpenTK 光照/材质演示程序：通过分层封装（Shader / VAO-VBO / Camera / Light / Material / SphereUseMaterial），把 OpenGL 光照管线中「几何—变换—光照—材质—着色器」各环节解耦，便于学习与扩展。
