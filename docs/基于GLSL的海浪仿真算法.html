基于 GLSL 的海浪生成算法

一、项目概述

1.1 项目简介(项目源码)

WinFormOpenGL1 是一个基于 Windows Win32 窗口框架的 OpenGL 实时海浪渲染程序。项目通过 GLSL 片段着色器（Fragment Shader）在 GPU 上实时生成逼真的海洋景观，核心算法源自 Alexander Alekseev (TDM) 的 Shadertoy 作品 "Seascape"，并适配到 OpenGL 3.3 Core Profile 环境。

3.3 基础噪声函数

海浪的随机性来源于两个基础函数：

3.3.1 哈希函数 hash

xxxxxxxxxx
float hash(vec2 p) {
    float h = dot(p, vec2(127.1, 311.7));
    return fract(sin(h) * 43758.5453123);
}

原理：对输入坐标做点积后取正弦，再取小数部分，产生 [0,1) 范围的伪随机值。常数 127.1、311.7、43758.5453123 是经验选取的魔法数字，确保哈希分布均匀。

3.3.2 值噪声 noise

xxxxxxxxxx
float noise(in vec2 p) {
    vec2 i = floor(p);           // 整数格点
    vec2 f = fract(p);           // 格内小数偏移
    vec2 u = f * f * (3.0 - 2.0 * f);  // Smoothstep 平滑插值
    return -1.0 + 2.0 * mix(
        mix(hash(i + vec2(0,0)), hash(i + vec2(1,0)), u.x),
        mix(hash(i + vec2(0,1)), hash(i + vec2(1,1)), u.x),
        u.y);
}

原理：

  1. 将连续坐标 p 分解为整数格点 i 和格内偏移 f

  2. 在四个相邻格点上用 hash 取随机值

  3. 用 Smoothstep 函数 f²(3-2f) 做双线性插值（比线性插值更平滑）

  4. 结果映射到 [-1, 1] 范围

该噪声为海浪表面的微小扰动提供基础，使波浪不显得过于规则。

3.4 单层波浪函数 sea_octave

sea_octave 是海浪生成的核心积木——它生成单层脊状波浪（Ridge Wave）：

xxxxxxxxxx
float sea_octave(vec2 uv, float choppy) {
    uv += noise(uv);                          // 1. 加噪扰动
    vec2 wv  = 1.0 - abs(sin(uv));           // 2. 脊状波形
    vec2 swv = abs(cos(uv));                  // 3. 余弦波形
    wv = mix(wv, swv, wv);                    // 4. 混合
    return pow(1.0 - pow(wv.x * wv.y, 0.65), choppy);  // 5. 尖锐化
}

逐步解析：

步骤 1 — 噪声扰动：uv += noise(uv)

  • 对 UV 坐标加入值噪声扰动，打破波的完美周期性

  • 这使得波浪看起来更自然，不像数学函数般规整

步骤 2 — 脊状波形：wv = 1.0 - abs(sin(uv))

  • sin(uv) 产生正弦波，值域 [-1, 1]

  • abs(sin(uv)) 取绝对值，值域 [0, 1]，形成三角波形状

  • 1.0 - abs(sin(uv)) 翻转，使得波峰在 0 处（值=1），波谷在 π/2 处（值=0）

  • 这种波形比纯正弦波更尖锐，更像真实海浪

步骤 3-4 — 波形混合：wv = mix(wv, swv, wv)

  • swv = abs(cos(uv)) 是余弦版本的绝对值

  • 用 wv 自身作为混合因子：波峰处（wv 大）偏向余弦波，波谷处偏向脊状波

  • 这进一步调整波形轮廓，使其更接近真实水面

步骤 5 — 尖锐化：pow(1.0 - pow(wv.x * wv.y, 0.65), choppy)

  • wv.x * wv.y 将二维波形合并为一维高度

  • 外层 pow(..., choppy) 用 choppy 参数控制波峰尖锐度

  • choppy 越大，波峰越尖锐陡峭；越小，波浪越平缓

  • 指数 0.65 调整波谷的平坦程度

3.5 分形布朗运动（fBm）—— 海面高度场

真实海面不是单一频率的波，而是多个频率叠加的复杂结构。算法通过分形布朗运动（Fractal Brownian Motion）实现：

3.5.1 高度场 SDF

xxxxxxxxxx
float map(vec3 p) {
    float freq   = SEA_FREQ;        // 初始频率 0.16
    float amp    = SEA_HEIGHT;      // 初始振幅 0.6
    float choppy = SEA_CHOPPY;      // 初始尖锐度 4.0
    vec2  uv     = p.xz;            // 取水平面坐标
    uv.x *= 0.75;                   // x 方向压缩（使波浪在 x 方向更长）


    float d, h = 0.0;
    for (int i = 0; i < ITER_GEOMETRY; i++) {
        d  = sea_octave((uv + SEA_TIME) * freq, choppy);   // 正向波
        d += sea_octave((uv - SEA_TIME) * freq, choppy);   // 反向波
        h += d * amp;                                         // 累加高度
        uv   *= octave_m;       // 旋转坐标（增加复杂性）
        freq  *= 1.9;           // 频率倍增（~2倍频程）
        amp   *= 0.22;          // 振幅衰减
        choppy = mix(choppy, 1.0, 0.2);  // 高频波更平缓
    }
    return p.y - h;  // 返回 SDF：正=水面之上，负=水面之下
}

关键设计：

  1. 双向波叠加：+SEA_TIME 和 -SEA_TIME 产生相向传播的波，叠加后形成驻波效果，使海面更复杂

  2. 八度旋转矩阵 octave_m = mat2(1.6, 1.2, -1.2, 1.6)：

    • 每层迭代对 UV 坐标做旋转+缩放

    • 打破各层波的方向对齐，避免出现明显的网格伪影

    • 行列式 = 1.6² - 1.2² = 1.0，是纯旋转+缩放（面积保持）

  3. 频率倍增 1.9：接近标准 2.0 倍频程，但略低于 2 以减少层间对齐

  4. 振幅衰减 0.22：每层振幅降为上一层的 22%，高频细节贡献递减

  5. 尖锐度渐变：choppy = mix(choppy, 1.0, 0.2)

    • 高频波的 choppy 逐渐趋近 1（即 pow(x, 1.0) = x，无尖锐化）

    • 物理意义：高频小波不应有尖锐波峰，只有低频大波才尖锐

  6. SDF 返回值 p.y - h：

    • p.y 是当前点的世界高度

    • h 是该位置的海面高度

    • 返回值为正 → 点在海面之上；为负 → 在海面之下；为零 → 在海面上

3.5.2 精细版 map_detailed

xxxxxxxxxx
float map_detailed(vec3 p) {
    // ... 与 map() 完全相同，但 ITER_FRAGMENT = 5（更多迭代层数）
}

  • map()（3 层）：用于光线步进的快速求交，牺牲精度换性能

  • map_detailed()（5 层）：用于法线计算的精确求值，更多细节层

这种"粗糙+精细"双版本策略是实时渲染中常见的优化手段。

3.6 光线步进——海面求交

3.6.1 算法原理

xxxxxxxxxx
float heightMapTracing(vec3 ori, vec3 dir, out vec3 p) {
    float tm = 0.0;           // 近端参数 t
    float tx = 1000.0;        // 远端参数 t
    float hx = map(ori + dir * tx);  // 远端高度差


    // 远端已在海面之上 → 射线未击中海面
    if (hx > 0.0) {
        p = ori + dir * tx;
        return tx;
    }


    float hm = map(ori);      // 近端高度差
    for (int i = 0; i < NUM_STEPS; i++) {
        // 二分法插值：按高度差比例取中间点
        float tmid = mix(tm, tx, hm / (hm - hx));
        p = ori + dir * tmid;
        float hmid = map(p);


        if (hmid < 0.0) {      // 中间点在海面下 → 远端收窄
            tx = tmid;
            hx = hmid;
        } else {                // 中间点在海面上 → 近端收窄
            tm = tmid;
            hm = hmid;
        }


        if (abs(hmid) < EPSILON) break;  // 命中
    }


    return mix(tm, tx, hm / (hm - hx));  // 最终插值
}

算法说明：

这是高度场光线步进（Heightfield Raymarching）的变体，采用二分搜索策略：

  1. 初始化近端 tm=0（相机位置）和远端 tx=1000

  2. 检查远端：若远端在海面之上，说明射线可能未与海面相交

  3. 每次迭代：

    • 按近远端的高度差比例计算中间点 tmid（类似线性插值的二分）

    • 评估中间点高度 hmid

    • 根据正负收缩搜索区间

  4. 达到精度阈值 EPSILON 或最大步数后停止

优势：相比等步长 Raymarching，二分搜索在高度场场景中收敛更快，通常 32 步即可获得精确结果。

3.6.2 法线计算

xxxxxxxxxx
vec3 getNormal(vec3 p, float eps) {
    vec3 n;
    n.y = map_detailed(p);
    n.x = map_detailed(vec3(p.x + eps, p.y, p.z)) - n.y;
    n.z = map_detailed(vec3(p.x, p.y, p.z + eps)) - n.y;
    n.y = eps;
    return normalize(n);
}

原理：前向有限差分法计算梯度。

  • 在 x 和 z 方向各偏移 eps 采样高度差

  • 构造梯度向量 (∂h/∂x, eps, ∂h/∂z) 并归一化得到法线

  • eps 随距离自适应：dot(dist, dist) * (0.1 / uResolution.x)——远处用更大的步长（因为远处细节不需要太精确）

3.7 相机系统

xxxxxxxxxx
vec3 getPixel(in vec2 coord, float time) {
    // 屏幕坐标 → NDC → 宽高比校正
    vec2 uv = coord / uResolution.xy;
    uv = uv * 2.0 - 1.0;
    uv.x *= uResolution.x / uResolution.y;


    // 相机参数
    vec3 ang = vec3(sin(time * 3.0) * 0.1,    // X轴轻微摇摆
                    sin(time) * 0.2 + 0.3,      // Y轴俯仰
                    time);                       // Z轴持续旋转（环绕）
    vec3 ori = vec3(0.0, 3.5, time * 5.0);      // 相机位置：沿Z轴前进
    vec3 dir = normalize(vec3(uv.xy, -2.0));    // 视线方向
    dir.z += length(uv) * 0.14;                  // 鱼眼畸变
    dir = normalize(dir) * fromEuler(ang);       // 应用旋转
    // ...
}

相机行为：

  • 相机沿 Z 轴持续前移（ori.z = time * 5.0），产生"飞行过海面"的效果

  • Y 方向有正弦摇摆，模拟海浪中的颠簸

  • time 用于 ang.z，使相机持续旋转，产生环绕视角

  • 鱼眼畸变 dir.z += length(uv) * 0.14 使边缘视野弯曲，增强沉浸感

3.8 海洋着色

3.8.1 海水颜色

xxxxxxxxxx
vec3 getSeaColor(vec3 p, vec3 n, vec3 l, vec3 eye, vec3 dist) {
    // 1. 菲涅尔反射
    float fresnel = clamp(1.0 - dot(n, -eye), 0.0, 1.0);
    fresnel = min(fresnel * fresnel * fresnel, 0.5);


    // 2. 反射色（天空）与折射色（水体）
    vec3 reflected = getSkyColor(reflect(eye, n));
    vec3 refracted = SEA_BASE + diffuse(n, l, 80.0) * SEA_WATER_COLOR * 0.12;


    // 3. 菲涅尔混合
    vec3 color = mix(refracted, reflected, fresnel);


    // 4. 水体深度衰减（波峰更亮）
    float atten = max(1.0 - dot(dist, dist) * 0.001, 0.0);
    color += SEA_WATER_COLOR * (p.y - SEA_HEIGHT) * 0.18 * atten;


    // 5. 高光
    color += specular(n, l, eye, 600.0 * inversesqrt(dot(dist, dist)));


    return color;
}

着色模型解析：

  1. 菲涅尔效应：fresnel = (1 - dot(n, -eye))³

    • 视线越平行水面（掠射角），反射越强

    • 视线越垂直水面（正视角），折射越强（能看到水下）

    • 三次方使过渡更锐利，上限 0.5 防止反射过强

  2. 反射色：getSkyColor(reflect(eye, n))——反射天空颜色

  3. 折射色：SEA_BASE + diffuse(...) * SEA_WATER_COLOR * 0.12

    • 深水基色 + 受光照影响的浅水色调

    • diffuse 使用 Modified Phong：pow(dot(n,l)*0.4+0.6, 80.0)

    • 系数 0.4 和 0.6 使暗部不至于全黑

  4. 深度衰减：(p.y - SEA_HEIGHT) * atten

    • 波峰处 p.y 较高，颜色更亮

    • 距离衰减 atten 使远处波浪变化减弱

  5. 高光：specular(n, l, eye, 600.0 * inversesqrt(dist²))

    • Blinn-Phong 高光

    • 高光指数随距离增大（inversesqrt 使远处高光更锐利）

3.8.2 天空颜色

xxxxxxxxxx
vec3 getSkyColor(vec3 e) {
    e.y = (max(e.y, 0.0) * 0.8 + 0.2) * 0.8;
    return vec3(pow(1.0 - e.y, 2.0), 1.0 - e.y, 0.6 + (1.0 - e.y) * 0.4) * 1.1;
}

  • e.y 是视线方向的垂直分量（仰角）

  • 仰角越高（看向天顶）→ 蓝色越深

  • 仰角越低（看向地平线）→ 偏白偏黄（地平线雾气效果）

3.8.3 天空与海面混合

xxxxxxxxxx
return mix(
    getSkyColor(dir),
    getSeaColor(p, n, light, dir, dist),
    pow(smoothstep(0.0, -0.02, dir.y), 0.2));

  • 当视线向上（dir.y > 0）时显示天空

  • 当视线向下（dir.y < 0）时显示海面

  • smoothstep 在 dir.y ∈ [-0.02, 0] 区间平滑过渡，避免地平线处出现硬边

6.2 性能优化策略

  1. 粗糙/精细双 SDF：光线步进用 3 层 fBm，法线计算用 5 层

  2. 自适应法线步长：远处用更大 eps，减少不必要的高频采样

  3. 早退机制：光线步进命中阈值即 break

  4. 全屏四边形：几何体极简，所有计算在片段着色器，避免 CPU-GPU 传输瓶颈

  5. 外部着色器文件：支持运行时修改效果，无需重新编译 C++

七、海浪生成与光照数学公式汇总

本节将项目中散布于各处的核心算法以标准数学符号集中表述，便于对照推导。记海面水平坐标 $\mathbf{uv}=(u,v)\in\mathbb{R}^2$，世界点 $\mathbf{p}=(p_x,p_y,p_z)$，时间 $t$，时间偏移 $T=1+t\cdot S$（$S=\text{SEA_SPEED}$）。

7.1 噪声与扰动

哈希函数（输入整数格点，输出 $[0,1)$ 伪随机值）：

hash(p)=fract(sin⁡(p⋅(127.1,311.7))⋅43758.5453123)

Smoothstep 平滑核（$f\in[0,1]$）：

u(f)=f2(3−2f)

值噪声（双线性插值四角哈希值，结果映射到 $[-1,1]$）：

noise(p)=−1+2mix(mix(h00,h10,ux),mix(h01,h11,ux),uy)

其中 $h_{ij}=\operatorname{hash}(\lfloor\mathbf{p}\rfloor+(i,j))$，$u_x=u(f_x)$，$u_y=u(f_y)$。

7.2 单层脊状波 sea_octave

设 $\mathbf{w}=\mathbf{uv}+\operatorname{noise}(\mathbf{uv})$（噪声扰动后的坐标），定义：

a=1−|sin⁡(w)|,b=|cos⁡(w)|
wv=mix(a,b,a)

单层波高（$\text{choppy}$ 控制尖锐度）：

sea_octave(uv,choppy)=(1−(wvx⋅wvy)0.65)choppy

7.3 分形布朗运动（fBm）海面高度场

记初始频率 $f_0=\text{SEA_FREQ}$，初始振幅 $a_0=\text{SEA_HEIGHT}$，初始尖锐度 $c_0=\text{SEA_CHOPPY}$，八度旋转矩阵 $M=\begin{pmatrix}1.6&1.2\-1.2&1.6\end{pmatrix}$（$\det M=1$）。第 $i$ 层参数递推：

fi+1=1.9fi,ai+1=0.22ai,ci+1=mix(ci,1,0.2),uvi+1=Muvi

海面高度（双向波叠加，$N$ 层）：

h(p)=∑i=0N−1[sea_octave((uvi+T)fi,ci)+sea_octave((uvi−T)fi,ci)]ai

其中 $\mathbf{uv}_0=(0.75\,p_x,\;p_z)$。粗糙版取 $N=3$（map），精细版取 $N=5$（map_detailed）。

高度场 SDF（正=水面之上，负=水面之下）：

map(p)=py−h(p)

7.4 高度场光线步进求交

射线方程 $\mathbf{r}(t)=\mathbf{o}+t\,\mathbf{d}$，近端 $t_m=0$，远端 $t_x=1000$。记 $h_m=\operatorname{map}(\mathbf{o})$，$h_x=\operatorname{map}(\mathbf{o}+t_x\mathbf{d})$。若 $h_x>0$ 则射线未击中海面。否则迭代二分搜索：

tmid=mix(tm,tx,hmhm−hx)=tm+(tx−tm)hmhm−hx
hmid=map(o+tmidd)
{tx←tmid,hx←hmid,hmid<0(中间点在水下，远端收窄)tm←tmid,hm←hmid,hmid≥0(中间点在水上，近端收窄)

当 $|h_{\text{mid}}|<\varepsilon$ 或达到 $\text{NUM_STEPS}=32$ 步时终止，最终命中参数：

thit=mix(tm,tx,hmhm−hx)

7.5 表面法线（前向有限差分）

设 $\varepsilon$ 为自适应步长（$\varepsilon=|\mathbf{d}_{\text{hit}}|^2\cdot\frac{0.1}{W}$，$W$ 为窗口宽度），梯度近似：

∂h∂x≈h(p+(ε,0,0))−h(p)ε,∂h∂z≈h(p+(0,0,ε))−h(p)ε

法线（此处精细版 $h$ 用 map_detailed）：

n=normalize(∂h∂x,ε,∂h∂z)

7.6 光照模型

记视线方向 $\mathbf{e}$（由像素指向相机，即 $-\mathbf{d}$），光源方向 $\mathbf{l}=\operatorname{normalize}(0,1,0.8)$。

Modified Phong 漫反射（半朗伯，避免暗部全黑）：

Ld(n,l,p)=(n⋅l⋅0.4+0.6)p

Phong 镜面高光（含归一化系数）：

r=reflect(e,n)=2(n⋅e)n−e
Ls(n,l,e,s)=s+88πmax(r⋅l,0)s

7.7 菲涅尔反射与海水着色

菲涅尔因子（掠射角增强反射，三次方锐化，上限 0.5）：

F=min((1−n⋅(−e))3,0.5)

反射色（反射方向取天空色）：

crefl=sky(reflect(e,n))

折射色（深水基色 + 漫反射影响）：

crefr=cbase+Ld(n,l,80)⋅cwater⋅0.12

距离衰减（远处波动减弱）：

A=max(1−∥dhit∥2⋅0.001,0)

最终海水颜色（菲涅尔混合 + 波峰增亮 + 距离相关高光）：

csea=mix(crefr,crefl,F)+cwater(py−H)⋅0.18⋅A+Ls(n,l,e,600∥dhit∥2)

其中 $H=\text{SEA_HEIGHT}$。

7.8 天空颜色与地平线混合

天空梯度（按仰角 $e_y$ 变化）：

ey′=(max(ey,0)⋅0.8+0.2)⋅0.8
sky(e)=1.1⋅((1−ey′)2,1−ey′,0.6+(1−ey′)⋅0.4)

天空/海面混合因子（地平线处平滑过渡）：

w=smoothstep(0,−0.02,dy)0.2
cpixel=mix(sky(d),csea,w)

7.9 后处理

时间缩放与鼠标交互：$t=uTime\cdot 0.3+uMouse_x\cdot 0.01$。Gamma 校正（提亮暗部）：

cout=cpixel0.65

7.10 相机射线

屏幕坐标 $\mathbf{c}\in\mathbb{R}^2$，分辨率 $(W,H)$：

uv=c(W,H)⋅2−1,uvx←uvx⋅WH

相机姿态角 $\boldsymbol{\theta}=\big(\sin(3t)\cdot 0.1,\;\sin(t)\cdot 0.2+0.3,\;t\big)$，位置 $\mathbf{o}=(0,\,3.5,\,5t)$。视线方向（含鱼眼畸变并经欧拉旋转 $R(\boldsymbol{\theta})$）：

d=normalize(normalize(uvx,uvy,−2)+(0,0,∥uv∥⋅0.14))R(θ)

八、结语

本项目展示了如何通过 GLSL 片段着色器实现高质量的实时海浪渲染。核心算法基于分形噪声 + 高度场光线步进技术，通过多层脊状波的叠加产生逼真的海面形态，配合菲涅尔反射和 Blinn-Phong 光照模型实现真实的着色效果。

整个海浪生成过程完全在 GPU 上完成，C++ 端仅负责窗口管理、着色器编译和 uniform 传递，充分发挥了 GPU 的并行计算能力。通过 Shader 类和 VAOWithVBOandEBO 类的封装，代码结构清晰，易于维护和扩展。
